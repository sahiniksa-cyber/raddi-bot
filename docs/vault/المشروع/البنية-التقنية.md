# البنية التقنية

## المكوّنات
| المكوّن | الوظيفة |
|---|---|
| **Node.js** (≥20) | لغة/بيئة التشغيل |
| **Express** | خادم الويب + لوحة التحكم (Dashboard) |
| **Baileys** (`7.0.0-rc13`) | مكتبة الاتصال بواتساب (بروتوكول الأجهزة المرتبطة) |
| **BullMQ** | نظام الطوابير (Queues) |
| **Redis** | تخزين مؤقت للطوابير |
| **PostgreSQL** | قاعدة البيانات الرئيسية (جلسات، محادثات، رسائل، إعدادات، فواتير) |
| **مزوّدو AI** | OpenAI / Anthropic / Google (عبر OpenRouter أو مباشر) |

## العمليتان (Processes)
النظام يشغّل **عمليتين داخل حاوية واحدة** على Railway، يديرهم `src/runtime/start-all.js`:

1. **`web`** (`src/server.js`) — لوحة التحكم + عامل الإرسال + مراقب الصحة. **أساسية**: لو ماتت، الحاوية تطلع.
2. **`ai-worker`** (`src/workers/ai-worker.js`) — يقرأ طابور الردود ويستدعي الذكاء الاصطناعي. **يعيد التشغيل تلقائياً** لو تعطّل.

أمر التشغيل: `npm run start:all`.

## أهم الملفات
| الموضوع | الملف |
|---|---|
| إدارة العمليات | `src/runtime/start-all.js` |
| خادم الويب + الإغلاق | `src/server.js` |
| **اتصال واتساب (Baileys)** | `src/services/whatsapp/baileys-connection-manager.js` |
| حفظ اعتماد واتساب في Postgres | `src/services/whatsapp/baileys-postgres-auth.js` |
| استقبال الرسائل → قاعدة البيانات | `src/services/whatsapp/message-ingest.service.js` |
| تشغيل البوت (إعدادات، lease) | `src/services/bot/runtime-bot.js` |
| عامل الذكاء الاصطناعي | `src/workers/ai-worker.js` |
| عامل الإرسال | `src/workers/outgoing-whatsapp-worker.js` |
| لوحة التحكم (الواجهة) | `dashboard/index.html` |

## جداول قاعدة البيانات المهمة
- **`whatsapp_sessions`** — حالة اتصال كل مستخدم: `status`، `connection_owner` (قفل/lease)، `desired_state`، `auth_state` (اعتماد Baileys)، آخر خطأ.
- **`messages`** — الرسائل الواردة والصادرة وحالاتها.
- **`conversations`** — محادثة لكل (مستخدم، عميل).
- **`jobs`** — مهام الطوابير المحفوظة للاسترجاع.
- **`bot_configs`** — إعدادات كل تاجر (مفاتيح AI، الموديل، البرومنت، جهات التصعيد).
- **`health_incidents`** — أعطال يفتحها/يغلقها المراقب تلقائياً.

## مفاتيح ضبط مهمة (env vars)
- `WA_QR_TIMEOUT_MS` (افتراضي 60000) — عمر الباركود.
- `WA_WEB_VERSION` — نسخة WA Web الاحتياطية (مثبّتة) — راجع [[قصة-مشكلة-الباركود]].
- `WA_CONNECTION_LEASE_MS` (120000) — مدة قفل الاتصال.
- `REPLY_DELAY_PRESET` (`1min`) — تأخير الرد قبل الإرسال.
- `AI_REPLY_DEBOUNCE_MS` (9000) — تجميع الرسائل السريعة.
