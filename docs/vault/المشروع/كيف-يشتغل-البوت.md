# كيف يشتغل البوت؟ (رحلة الرسالة)

من لحظة ما يرسل العميل رسالة، لين يوصله الرد، الرسالة تمر بهذي المحطات:

```
العميل يرسل رسالة على واتساب
        │
        ▼
① اتصال واتساب (Baileys)  ← src/services/whatsapp/baileys-connection-manager.js
   يستقبل الرسالة ويفلتر (يتجاهل: القروبات، الحالة، رسائل البوت نفسه)
        │
        ▼
② خدمة الاستقبال (Ingest) ← src/services/whatsapp/message-ingest.service.js
   يحفظ الرسالة في قاعدة البيانات + يحطها في طابور الذكاء الاصطناعي
   (ينتظر ٩ ثواني عشان يجمّع الرسائل السريعة من نفس العميل)
        │
        ▼
③ طابور ai-replies (Redis)
        │
        ▼
④ عامل الذكاء الاصطناعي (ai-worker) ← src/workers/ai-worker.js
   يقرأ الرسائل، يستدعي مزوّد الذكاء الاصطناعي، يكتب الرد
        │
        ▼
⑤ طابور outgoing-whatsapp (Redis)
        │
        ▼
⑥ عامل الإرسال ← src/workers/outgoing-whatsapp-worker.js
   ينتظر الاتصال يكون جاهز (لين ٤٥ ثانية) ثم يرسل الرد
        │
        ▼
العميل يستلم الرد ✅
```

## ليش الرد يتأخّر ~دقيقة؟
هذا **مقصود** (عشان يبان طبيعي مثل موظف بشري)، مو عطل. الحساب:
- ٩ ثواني تجميع الرسائل +
- ~٥ ثواني استدعاء الذكاء الاصطناعي +
- ٥٠-٧٥ ثانية تأخير الرد (الإعداد الافتراضي `1min`)
- **المجموع: ~٦٥-٩٠ ثانية.**

لو تبي أسرع، غيّر إعداد "تأخير الرد" في لوحة التحكم.

## نقاط مهمة
- كل محطة **حدود واضحة** — لو صار عطل، نعرف نحدد وين بالضبط. التفاصيل في [[البنية-التقنية]] و[[مشاكل-معروفة-وحلولها]].
- المحطة الأولى (الاتصال بواتساب) هي أكثر شي سبّب مشاكل — [[قصة-مشكلة-الباركود]].
