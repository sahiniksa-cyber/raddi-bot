## قبلها (من الذاكرة العامة — مختصر)
- بناء عقل البوت، نظام الحصص (Quota)، إخفاء lid، متغيّرات المنتجات.
- استقرار الاتصال (lease / single-flight / boot-recovery / signal-keys).
- جذر Bad MAC (getMessage + throttle + keystore debounce).
- ميزة تعديل البرومنت من قروب التصعيد.
- وحدة ردود إنستقرام معزولة (خلف `INSTAGRAM_ENABLED`).
- حادثة امتلاء قرص Postgres (2026-07-07) → Resize + تنظيف جدول `messages`.
