# مشاكل معروفة وحلولها

فهرس الأعطال المتكررة على المنصة وحلّها. **طابق العرض هنا قبل أي تشخيص جديد** — أغلب المشاكل مكررة.

## اتصال واتساب
| العطل | العلامة | الحل |
|---|---|---|
| **تعارض 440** | `code=440 connectionReplaced`، اتصال يتذبذب | نسخة ثانية متصلة بنفس الرقم — أوقفها. مشكلة تشغيلية مو كود. |
| **باركود ميت (428)** | باركود يظهر بس المسح يفشل بشكل متقطّع | ✅ مُصلَح بـ `b72aec3` — [[قصة-مشكلة-الباركود]] |
| **عاصفة ربط** | ٤٠٠+ باركود، كل السوكِتات تُخنق | ✅ مُصلَح بـ `c521b34` — تشغيل يدوي فقط لغير المربوط |
| **اتصل ثم انفصل فوراً** | `connected` ثم `logged out` خلال ثواني | واتساب شال الجهاز — راجع [[ربط-التاجرة-2026-07-29]] |
| **البوت متوقف يدوياً** | الحالة `stopped` | اضغط "تشغيل البوت" — مو عطل |

## الذكاء الاصطناعي / الردود
| العطل | العلامة | الحل |
|---|---|---|
| **عامل AI متوقف** | رسائل عالقة كثيرة، الطابور 0، لا سطور `[ai-worker]` | تأكد `npm run start:all` يشغّل العامل |
| **الرد بطيء ~دقيقة** | ما فيه أخطاء | **طبيعي** — تأخير مقصود، راجع [[كيف-يشتغل-البوت]] |
| **رسائل عالقة + خطأ duplicate key** | فشل في الطابور | مُصلَح بإضافة UUID لكل رد |

## لوحة التحكم / قاعدة البيانات
| العطل | العلامة | الحل |
|---|---|---|
| **الداشبورد يرجع 500** | صفحات لا تفتح | تحقق من `DATABASE_URL` وحالة الترحيلات (migrations) |
| **امتلاء قرص Postgres** | توقف كامل | Resize للـ volume + تنظيف جدول `messages` |

## قاعدة ذهبية
> [!tip] الجذر أولاً
> لا حلول سطحية لمشاكل عقل البوت أو الاتصال — نمسك السبب الجذري أول بالأدلة (لوقات + قراءة قاعدة البيانات)، **بدون تجارب حية ترسل واتساب حقيقي**.
