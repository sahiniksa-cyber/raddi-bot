# أوامر مفيدة

> [!note] لمين هذي؟
> أغلب هذي الأوامر يستخدمها المبرمج أو جلسة الـ AI أثناء الفحص. حُطّت هنا كمرجع، مو لازم تشغّلها بنفسك.

## قراءة كود النسخة الحيّة (production)
عشان تفحص الكود **المنشور فعلاً** مو نسخة محلية قديمة:
```bash
git fetch origin production
git show origin/production:src/services/whatsapp/baileys-connection-manager.js
```

## معرفة حالة الفرع الحالي
```bash
git rev-parse --abbrev-ref HEAD
git rev-parse origin/production
```

## الاختبارات
```bash
node --test "tests/*.test.js"
```

## فحص الثغرات (تجاهل ثغرات التطوير)
```bash
npm audit --omit=dev
```

## فحص Railway (عبر أداة Railway)
هذي تتم عبر أداة Railway MCP (مو أوامر شِل)، وتشمل:
- **حالة النشر:** `get-status` للمشروع `1e61b9ce-df80-40d3-96d3-18d5394dbef9`.
- **آخر عمليات النشر:** `list-deployments` للخدمة `web`.
- **اللوقات:** `get-logs` مع فلتر — أمثلة فلاتر مفيدة:
  - حالة الاتصال: `connection OR connected OR qr_ready OR 428 OR 440`
  - نجاح الربط: `isNewLogin=true OR "creds.update begin" OR restartRequired OR 515`
  - جلسة مستخدم معيّن: أول ٨ خانات من الـ userId (مثال `d579ac09`)

## قراءة إشارات الربط في اللوق
| ما تشوفه في اللوق | معناه |
|---|---|
| `[qr] Baileys QR ready version=N` | ظهر باركود جديد (طبيعي، يتجدّد كل ~٦٠ث) |
| `close ... code=428 ... qr_ready` | باركود انتهت مهلته بدون مسح (طبيعي) |
| `isNewLogin=true` | **أحد مسح الباركود ووصل الخادم** ✅ |
| `code=515 reason=restartRequired` | **الربط اكتمل**، إعادة تشغيل للاتصال المصادَق ✅ |
| `creds.update saved` | تم حفظ اعتماد الجلسة ✅ |
| `logged out` / `unlink-alert` | واتساب فصل الجهاز ❌ |
| `code=440 connectionReplaced` | نسخة ثانية متصلة بنفس الرقم |
