## وش نبني في هذي المرحلة
1. **بوابة CI** — تشغّل كل الاختبارات على كل push/PR وتفشل لو فشل أي اختبار. ✅ *(تم — ملف `.github/workflows/ci.yml`)*
2. **حماية فرع production** — إعداد على GitHub يمنع الدمج/النشر إلا لو CI أخضر. ⏳ *(يحتاج تفعيل من المالك — خطوة قادمة)*
3. **انضباط الدمج عبر PR** — التعديلات تدخل production عبر Pull Request (لا push مباشر). ⏳
4. **أقفال سلوك (Behavior-lock)** — اختبارات تثبّت سلوك الكود الحساس (الردود/الحملات/الأسعار) فما يتغيّر بالغلط. ⏳
5. **اختبارات منع التكرار** — كل عطل سابق (من [[مشاكل-معروفة-وحلولها]]) يتحوّل لاختبار يمنع رجوعه. ⏳
