# تصميم: دمج الرد الفوري مع إجابة السؤال (Approach A)

**التاريخ:** 2026-06-06
**الحالة:** مُصادق عليه (المستخدم اختار Approach A — الرد الفوري حرفياً + جواب الذكاء)

## المشكلة
في `ai-worker`، عند تطابق رد فوري (`findAutoReply`) يحدث short-circuit يرسل **النص المحفوظ فقط** ويُسقط أي سؤال إضافي في نفس الرسالة. مثال: "السلام عليكم، بكم ادوبي 4 أشهر؟" → يرسل التحية فقط، ويبلع سؤال السعر.

## الهدف
أي رسالة فيها محفّز رد فوري **+ سؤال/طلب زائد** → ترسل **الرد الفوري حرفياً** + **جواب الذكاء على باقي الرسالة** (بما فيها أسئلة متعددة). عام لكل الردود الفورية (منصة للبيع)، مو خاص بالتحية.

## المعمارية
دالة نقية جديدة في `src/services/bot/platform-features.js`:
```js
collectInstantReplies(config, text) → {
  matched: [{ keyword, reply }],   // كل الردود الفورية المطابقة (حرفية)
  hasExtraQuestion: boolean,       // هل بقي سؤال/طلب بعد إزالة المحفّزات؟
}
```
- يبقى `findAutoReply` كما هو (يستخدمه كود آخر)؛ نضيف `collectInstantReplies` بجانبه (DRY: `collectInstantReplies` يصبح الأساس و`findAutoReply` يلتف عليه بإرجاع أول `matched.reply`).
- **كشف hasExtraQuestion:** نطبّع النص، نحذف كل الكلمات المفتاحية المطابقة، فإذا بقي علامة استفهام (؟/?) أو كلمة استفهام/طلب (كم/وش/متى/كيف/هل/وين/ليش/ابي/ابغى/عندكم/في) أو ≥2 كلمة ذات معنى (طول ≥2) → `true`.

## تدفق ai-worker (يستبدل سطر الـ instant short-circuit)
```
collectInstantReplies(config, text):
  matched=[] → الذكاء العادي (لا تغيير)
  matched + !hasExtraQuestion → أرسل النص الفوري حرفياً وحده (مسار سريع، كالحالي).
                                 (عند تعدد المطابقات: ادمجها بسطر فاصل)
  matched +  hasExtraQuestion → وضع الدمج:
     1. cannedText = matched.map(m=>m.reply).join('\n')   // حرفي
     2. aiAnswer = AIClient.getReply(history, { instantContext })  // يجاوب الباقي
        تعليمة إضافية للنظام: "هذي الأجزاء مُجاب عليها مسبقاً: <cannedText>.
        جاوب فقط باقي رسالة العميل بدون تكرارها. لو ما فيه شي إضافي، رد بإيجاز مناسب."
     3. final = cannedText + '\n' + aiAnswer  (لو aiAnswer غير فارغ ومختلف)
     4. أرسل final
```

## معالجة الأخطاء
- فشل الذكاء في وضع الدمج → أرسل `cannedText` حرفياً (العميل ما يضيع).
- `aiAnswer` فارغ/تافه أو شبه مطابق للـcanned → أرسل `cannedText` وحده.
- أسئلة متعددة → الذكاء يجاوبها كلها (مُثبَت سابقاً على gpt-4o).

## التغيير المقصود في اختبار قائم
`tests/platform-features.test.js`: الحالة "لو سمحت كم سعر الشحن للرياض؟" (keyword "سعر الشحن") تتحول من canned-وحده إلى canned + جواب ذكاء (سؤال زائد "للرياض"). يُحدَّث الاختبار ليعكس السلوك الجديد المقصود.

## الاختبار
- **وحدة** (`collectInstantReplies`): محفّز وحده → `hasExtraQuestion=false`؛ محفّز+سؤال → `true`؛ محفّزات متعددة؛ كلمة موضوع بدون سؤال زائد → `false`؛ نص بلا تطابق → `matched=[]`.
- **تكامل** (ai-worker): وضع الدمج يرسل canned+answer؛ المسار السريع يبقى؛ فشل الذكاء → canned.
- **حيّ** (gpt-4o): "السلام عليكم بكم ادوبي 4 أشهر؟" → الرد يبدأ بالتحية الحرفية ثم سعر/سؤال أدوبي؛ ورسالة بسؤالين → الاثنين مُجابان.

## خارج النطاق (YAGNI)
لا تغيير على حقن المعرفة/الـvalidator القائمين؛ لا تغيير على الداشبورد.
